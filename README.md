# Resume Website

A personal resume website built with HTML and CSS for my Web Development mid-term project.

**Live site:** https://abhijae-arch.github.io/resume-website/

## Features
- Responsive layout with a flexbox navigation bar
- Card layouts using CSS Grid
- Google Fonts and a consistent colour palette
- Hover effects and scroll animation

## Files
- `index.html` - page content
- `style.css` - styling
